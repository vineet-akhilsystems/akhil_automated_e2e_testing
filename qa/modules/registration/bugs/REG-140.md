# Bug Report: REG-140 — Leap Day DOB (`29/02/2000`) Silently Clamped to `28/02/2000` While Typing

- **Case ID:** `REG-140`
- **Module:** Patient Registration — Basic Information (`DOB` / `DateField`)
- **Severity:** High (Clinical / Demographic Data Corruption)
- **Priority:** P1
- **Environment:** `https://demo.augastam.com/registration` (Build `2.0.66`, Tenant: `Miracle HIS Demo`, Facility: `Akhil Demo2 Delhi`)
- **Status:** Confirmed Product Bug

---

## 1. Summary
When a user types a valid leap-year Date of Birth (`29022000` -> `29/02/2000`) into the **DOB** input (`DD/MM/YYYY`), the input's `onChange` handler validates the day against the month **on the 5th digit typed** (when only the first digit of the year, `"2"`, has been entered). Because year `"2"` is not a leap year (`2 % 4 !== 0`), the component immediately overwrites `"29"` with `"28"` in state before the remaining digits `"000"` (`2000`) are typed.

---

## 2. Steps to Reproduce
1. Open Patient Registration (`/registration/1101f999-7c91-4ba5-a52b-a80d728c588e`).
2. Focus the **DOB** (`DD/MM/YYYY`) input in the **Basic Information** section.
3. Type the digits `29022000` sequentially (representing `29/02/2000`, a valid leap day in the year 2000).
4. Observe the value inside the **DOB** input and the auto-calculated **Age** fields (`Y / M / D`).

---

## 3. Expected vs. Actual Result
- **Expected:**
  - **DOB** displays `29/02/2000`.
  - **Age** calculates accurately from `29/02/2000`.
- **Actual:**
  - **DOB** is silently rewritten to `28/02/2000` as soon as the 5th digit (`2`) is typed.
  - **Age** calculates from `28/02/2000` (`26Y 7M 30D`).
  - No warning or toast is displayed to the operator, causing silent demographic inaccuracy on the patient record.

---

## 4. Root Cause Analysis (Hypothesis with Code Reference)
- **File:** `custom-form-builder/src/components/registration/builder/DateField.jsx:114-164` (`CustomInput.handleInputChange`)
- **Code Logic:**
  ```javascript
  // DateField.jsx:145-162
  // Check and modify the day if it exceeds the maximum days for the entered month and year
  if (newValue.length > 5) {
    const enteredYear = newValue.slice(6, 10);
    const enteredMonth = newValue.slice(3, 5);
    const enteredDay = newValue.slice(0, 2);

    const lastDayOfMonth = new Date(enteredYear, enteredMonth, 0).getDate();

    // Check for leap year if the month is February (02)
    const isLeapYear = (enteredYear % 4 === 0 && enteredYear % 100 !== 0) || (enteredYear % 400 === 0);
    const maxDaysInMonth = (enteredMonth === '02' && isLeapYear) ? 29 : lastDayOfMonth;

    if (parseInt(enteredDay, 10) > maxDaysInMonth) {
      newValue = `${maxDaysInMonth.toString().padStart(2, '0')}/${enteredMonth}/${enteredYear}`;
    }
  }
  ```
- **Why It Fails:**
  - After formatting with slashes (`DD/MM/YYYY`), typing the 5th digit `2` produces `newValue = "29/02/2"`, which has `newValue.length === 7` (`> 5`).
  - At that moment, `enteredYear` is `"2"`, `enteredMonth` is `"02"`, and `enteredDay` is `"29"`.
  - `new Date("2", "02", 0).getDate()` evaluates to `28`, and `isLeapYear` for `"2"` is `false`.
  - `maxDaysInMonth` evaluates to `28`. Because `29 > 28`, `newValue` is immediately mutated to `"28/02/2"`.
  - When the user finishes typing `"000"`, the input becomes `"28/02/2000"` — the original `"29"` was already lost on the 5th keystroke.

---

## 5. Recommended Fix
Only clamp `enteredDay` against the year's leap-year rules once all 4 digits of the year have been entered (`newValue.length === 10`), or allow up to `29` days for February while `enteredYear.length < 4`:

```javascript
// Wait until the full 4-digit year is entered before clamping February 29
if (newValue.length === 10) {
  const enteredYear = parseInt(newValue.slice(6, 10), 10);
  const enteredMonth = newValue.slice(3, 5);
  const enteredDay = parseInt(newValue.slice(0, 2), 10);

  const isLeapYear = (enteredYear % 4 === 0 && enteredYear % 100 !== 0) || (enteredYear % 400 === 0);
  const lastDayOfMonth = new Date(enteredYear, parseInt(enteredMonth, 10), 0).getDate();
  const maxDaysInMonth = (enteredMonth === '02' && isLeapYear) ? 29 : lastDayOfMonth;

  if (enteredDay > maxDaysInMonth) {
    newValue = `${maxDaysInMonth.toString().padStart(2, '0')}/${enteredMonth}/${enteredYear}`;
  }
}
```
