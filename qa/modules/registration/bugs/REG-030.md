# Bug / Requirement Gap Report: REG-030 / REG-031 / REG-037 — Name & Title/Gender Validation Issues (Digits Silently Stripped, `@#` Symbols Saved in First Name, `Title: Mrs.` + `Gender: Male` Accepted)

- **Case IDs:** `REG-030`, `REG-031`, `REG-037` (and `REG-134`)
- **Module:** Patient Registration — Basic Information (`First Name`, `Title`, `Gender`)
- **Severity:** Medium (Identity Data Quality & Silent Input Mutation)
- **Priority:** P2
- **Environment:** `https://demo.augastam.com/registration` (Build `2.0.66`, Tenant: `Miracle HIS Demo`)
- **Status:** Confirmed Validation & Config Defect (Verified Live with Created UHIDs)

---

## 1. Summary
1. **`REG-031` (Special Symbols `@#` Saved in First Name):** Typing `Ag@nt#` into **First Name** and clicking **Save** is accepted without error and creates **UHID `ASNR0000000427`** with `first_name = "Ag@nt#"`, while legitimate punctuation like apostrophes (`D'Souza`, `REG-130`) and hyphens (`Anne-Marie`, `REG-131`) are also allowed because no character whitelist regex is configured.
2. **`REG-030` & `REG-134` (Digits Silently Stripped From Name Input Instead of Flagging Error):** Typing `Agent123` into **First Name** silently strips `123` while typing and saves `"Agent"` (**UHID `ASNR0000000426`** and **UHID `ASNR0000000439`**).
3. **`REG-037` (`Title: Mrs.` With `Gender: Male` Not Flagged or Locked):** Setting `Title = Mrs.` and `Gender = Male` does not trigger a mismatch error or block Save (**UHID `ASNR0000000422`**). Note: Selecting `Title = Mrs.` auto-selects `Gender = Female` initially, but if the user manually selects `Gender = Male` afterward (or selects `Gender = Male` then `Title = Mrs.` depending on order), there is no save-time consistency validation between `Title` and `Gender`.

---

## 2. Recommended Fix
1. Configure a name character-class rule on `First Name`, `Middle Name`, and `Last Name` that permits letters, spaces, dots (`.`), hyphens (`-`), and apostrophes (`'`), while rejecting symbols like `@`, `#`, `$`, `%`, `*`.
2. Add a cross-field consistency check on Save (or confirmation warning) when gender-specific titles (`Mr.`, `Mrs.`, `Miss`, `Ms.`) contradict the selected `Gender`.
