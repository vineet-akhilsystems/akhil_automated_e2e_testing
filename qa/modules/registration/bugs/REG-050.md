# Bug / Requirement Gap Report: REG-050 / REG-151 — Invalid Emails (`agent@`, `agent testing@example.com`) Are Accepted and Saved

- **Case IDs:** `REG-050`, `REG-151`
- **Module:** Patient Registration — Basic Information (`Email` field validation & Save check)
- **Severity:** Medium-High (Malformed Contact Data Persisted to DB)
- **Priority:** P2
- **Environment:** `https://demo.augastam.com/registration` (Build `2.0.66`, Tenant: `Miracle HIS Demo`)
- **Status:** Confirmed Validation & Save-Bypass Defect (Verified Live with Created UHIDs)

---

## 1. Summary
When an operator enters an incomplete email (`agent@`) or an email containing spaces (`agent testing@example.com`) into the **Email** field and clicks **Save**, the registration succeeds and persists the invalid email to the database:
- **`REG-050`:** `email = "agent@"` -> Saved as **UHID `ASNR0000000431`**.
- **`REG-151`:** `email = "agent testing@example.com"` -> Saved as **UHID `ASNR0000000450`** (and `ASNR0000000441`).

---

## 2. Root Cause & Code Logic
1. **No Email Regex Configured in Live Webpart (`webpart_latest_version__5b5bc4c1-bafb-4432-b3f2-caaa0a4c2e7f.json`):**
   - Field `id: 7` (`Email`, `column: "email"`, `type: "text"`) has `"regExpression": ""` and `"required": false`.
2. **Save Only Checks Non-Empty Required Fields (`custom-form-builder/src/pages/registration/RegistrationPreview.jsx:2882-2925`):**
   - `validateRequiredFields()` skips any field where `!field?.attributes?.required` and never calls `validateFieldValue()` from `WebpartUtils.js`.
   - While bulk patient import validates email format on the backend, `POST /patient-registration/create` performs no email format check.

---

## 3. Recommended Fix
1. Configure a standard email regex (`^[^\s@]+@[^\s@]+\.[^\s@]+$`) on the `Email` field in the `Basic Information` webpart (or add built-in email validation when `column === 'email'` in `WebpartUtils.js`).
2. Call `validateFieldValue()` across all non-empty optional fields inside `handleSave()` (`RegistrationPreview.jsx:2882`) so invalid optional fields block Save with a clear error message.
